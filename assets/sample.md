# MD Viewer 使用說明

一個支援 **macOS、Windows、iOS、Android** 的 Markdown 閱讀器。這份文件同時也是功能展示，往下捲動看看各種元素的樣子。

> [!TIP]
> 點右上角的 **大綱** 可以快速跳到任一章節；閱讀時大綱會自動標示目前的位置。

## 版面配置

畫面會依 **視窗寬度** 自動切換：

![三種版面](images/layouts.svg)

| 情境 | 寬度 | 版面 |
| :--- | :---: | :--- |
| 手機直向 | < 600 | 手機版：上方工具列、側滑檔案清單、底部大綱 |
| 手機橫向 | ≥ 480 且橫向 | 電腦版（大綱從右側滑出） |
| 平板（直向／橫向） | ≥ 600 | 電腦版 |
| 電腦寬螢幕 | ≥ 1000 | 電腦版，大綱固定在右側 |

旋轉手機時會即時切換，並 **保留閱讀位置**。

## 開啟檔案

- 點 **開啟檔案** 選擇 `.md` 檔
- 電腦版可以 **開啟資料夾**，側邊欄會列出裡面所有 Markdown 檔案
- 電腦版可以直接把檔案或資料夾 **拖曳** 進視窗
- 從 Finder／檔案總管「打開方式」、iOS「檔案」App 的分享、Android 的「開啟方式」也可以
- 檔案在外部編輯器存檔後，會 **自動重新載入**

> [!NOTE]
> 手機上開啟的檔案會複製一份保存在 App 內（「我的檔案」），之後不需要原始檔也能再次開啟。

### 鍵盤快捷鍵（電腦版）

| 功能 | macOS | Windows |
| --- | --- | --- |
| 開啟檔案 | ⌘O | Ctrl+O |
| 開啟資料夾 | ⇧⌘O | Ctrl+Shift+O |
| 重新載入 | ⌘R | Ctrl+R |
| 顯示／隱藏側邊欄 | ⌘B | Ctrl+B |
| 放大／縮小文字 | ⌘+ ／ ⌘- | Ctrl++ ／ Ctrl+- |
| 還原文字大小 | ⌘0 | Ctrl+0 |
| 設定 | ⌘, | Ctrl+, |

## Markdown 支援

### 文字樣式

**粗體**、*斜體*、~~刪除線~~、`行內程式碼`，以及 [外部連結](https://flutter.dev)。
文件內連結也可以用，例如跳到 [程式碼區塊](#程式碼區塊)。

### 清單

1. 有序清單
2. 第二項
   - 巢狀項目
   - 另一個巢狀項目
3. 第三項

- [x] 已完成的任務
- [ ] 尚未完成的任務

### 程式碼區塊

```dart
void main() {
  final greeting = 'Hello, Markdown!';
  print(greeting);
}
```

```json
{
  "name": "mdviewer",
  "platforms": ["macos", "windows", "ios", "android"]
}
```

每個程式碼區塊右上角都有 **複製** 按鈕，長行可以左右捲動。
